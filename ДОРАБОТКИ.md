# EliteLinux — доработки

Список изменений, которые нужно внести в сборку. Пополняется по ходу тестирования.

## Из тестирования

- [x] **Flameshot как системный скриншотер.** Поставить `flameshot` вместо
  `xfce4-screenshooter` и повесить его на клавишу Print Screen
  (`flameshot gui`), чтобы скриншот с разметкой делался одной клавишей.
- [x] **VLC как видеоплеер.** Добавить `vlc` и сделать его плеером по умолчанию
  для видео и аудио.
- [x] **AnyDesk для удалённой помощи.** Подключить официальный APT-репозиторий AnyDesk
  (`deb.anydesk.com`) и поставить `anydesk`, чтобы получать обновления вместе с системой.
  - Автозапуск не нужен: отключить службу `anydesk` при старте системы
    (`systemctl disable anydesk`) и автозапуск в сеансе пользователя.
  - Пароль неконтролируемого доступа — общий, совпадает с паролем `eliteadmin`.
    В репозиторий его не класть: задавать при установке (`anydesk --set-password`)
    из секрета, который передаётся сборке отдельно.
  - Сделано: `secrets/anydesk-password` → разовая служба первой загрузки
    `elite-anydesk-password` (поднимает AnyDesk, задаёт пароль, останавливает,
    удаляет файл). Пароль лежит в образе открытым текстом (только root) — тот, у кого
    флешка, может его прочитать.

- [x] **Экран входа переделать.** Окно ввода — по центру экрана, логотип — над ним,
  выбор учётки явно подписан: «Менеджер» / «Администратор». slick-greeter так не умеет
  (окно всегда слева, логотип только в углу) — нужен другой greeter.
- [x] **Загрузочное меню ISO** — см. «Установка» ниже.

## Установка (решено 26.10.2026)

- [x] **Загрузчик флешки — GRUB и для BIOS, и для UEFI** (вместо isolinux): кириллица
  в меню и поиск установленной системы. Фон — графит с короной, таймаут 5 с.
  Пункты: «Установить EliteLinux», «Запустить без установки»; служебные пункты Debian убрать.
  По умолчанию — «Загрузить установленную систему», если на диске найдена EliteLinux,
  иначе «Установить EliteLinux».
- [x] **Установщик Calamares** в теме графит + золото, на весь экран, сразу после загрузки
  (без рабочего стола; если закрыть — открывается live-сессия). Экраны:
  1. «Добро пожаловать» — логотип, железо, проверка требований (предупреждение,
     если ОЗУ < 4 ГБ или диск < 60 ГБ);
  2. «Диск» — список дисков с размером и типом, остальные диски не трогаем,
     предупреждение «все данные будут удалены». **SSD по умолчанию Calamares выбирать
     не умеет** — выбран первый диск, тип дисков виден на экране приветствия;
  3. «Установка» — прогресс и слайды с железом ПК (без рекламы);
  4. «Готово» — «Извлеките флешку», кнопка «Перезагрузить».
  Язык (ru), раскладки (us,ru; Alt+Shift), часовой пояс (Europe/Moscow) не спрашиваются.
- [x] **Извлечение флешки:** после «Перезагрузить» — экран на весь монитор
  «Извлеките установочную флешку», перезагрузка сама, как только флешка отключена.
  Проверен вариант с CD (диск выбрасывается, перезагрузка); с USB-флешкой — проверить
  на железе.
- [x] **Разметка:** весь выбранный диск, одна ФС ext4, без шифрования.
- [x] **Имя компьютера** — автоматически: `elite-` + последние 6 символов MAC.
- [x] **Учётки:** `manager` («Менеджер», пароль общий) и `eliteadmin` («Администратор»,
  пароль общий, в образе только хэш). Вход всегда через экран входа, без автовхода.
- [x] **Паспорт ПК:** процессор, ОЗУ, диск (модель, размер, SSD/HDD), видеокарта,
  сеть и MAC, серийный номер платы — на слайдах и в файле `/etc/elite/hardware.txt`.
- [x] **Без интернета:** всё ставится с флешки, обновления — после подключения к сети.

## Известные хвосты (найдены при сборке)

- [ ] **EliteSIP: зависимость `libicu74`.** Пакет собран под Ubuntu 24.04, в Debian 13
  есть только `libicu76`. Сейчас `scripts/prepare-packages.sh` при сборке меняет
  зависимость на `libicu76 | libicu74`; правильно — поправить упаковку в проекте EliteSIP
  (`packaging/` в Linux EliteSip). Не сделано: диск EliteDev1 смонтирован только для
  чтения (`errors=remount-ro` — возможно, ошибки ФС).
- [ ] **Яндекс Телемост — нужно приложение, не веб-ярлык.** Официального клиента для Linux
  нет: по системным требованиям Яндекса только Windows и macOS, API установщика отдаёт
  только `v2-win64` и `v2-mac`. Варианты — Windows-клиент через Wine (камера и
  демонстрация экрана могут не работать) или отдельное окно-приложение на веб-версии.
  Ждёт решения.
- [x] **Оптимизация под HDD:** своп в zram (половина ОЗУ, zstd), `vm.swappiness=150`,
  BFQ для HDD и mq-deadline для SSD (udev), preload, отключены ModemManager,
  cups-browsed, man-db и e2scrub. Проверить на A6 с HDD.
- [ ] **Telegram в `/opt/telegram`.** Каталог доступен на запись группе `users`, чтобы
  работало встроенное автообновление; проверить, что обновление действительно проходит.
