# EliteLinux — доработки

Список изменений, которые нужно внести в сборку. Пополняется по ходу тестирования.

## Из тестирования

- [ ] **Flameshot как системный скриншотер.** Поставить `flameshot` вместо
  `xfce4-screenshooter` и повесить его на клавишу Print Screen
  (`flameshot gui`), чтобы скриншот с разметкой делался одной клавишей.
- [ ] **VLC как видеоплеер.** Добавить `vlc` и сделать его плеером по умолчанию
  для видео и аудио.
- [ ] **AnyDesk для удалённой помощи.** Подключить официальный APT-репозиторий AnyDesk
  (`deb.anydesk.com`) и поставить `anydesk`, чтобы получать обновления вместе с системой.
  - Автозапуск не нужен: отключить службу `anydesk` при старте системы
    (`systemctl disable anydesk`) и автозапуск в сеансе пользователя.
  - Пароль неконтролируемого доступа — общий, совпадает с паролем `eliteadmin`.
    В репозиторий его не класть: задавать при установке (`anydesk --set-password`)
    из секрета, который передаётся сборке отдельно.

- [ ] **Экран входа переделать.** Окно ввода — по центру экрана, логотип — над ним,
  выбор учётки явно подписан: «Менеджер» / «Администратор». slick-greeter так не умеет
  (окно всегда слева, логотип только в углу) — нужен другой greeter.
- [ ] **Загрузочное меню ISO** — см. «Установка» ниже.

## Установка (решено 26.10.2026)

- [ ] **Загрузчик флешки — GRUB и для BIOS, и для UEFI** (вместо isolinux): кириллица
  в меню и поиск установленной системы. Фон — графит с короной, таймаут 5 с.
  Пункты: «Установить EliteLinux», «Запустить без установки»; служебные пункты Debian убрать.
  По умолчанию — «Загрузить установленную систему», если на диске найдена EliteLinux,
  иначе «Установить EliteLinux».
- [ ] **Установщик Calamares** в теме графит + золото, на весь экран, сразу после загрузки
  (без рабочего стола; если закрыть — открывается live-сессия). Экраны:
  1. «Добро пожаловать» — логотип, железо, проверка требований (предупреждение,
     если ОЗУ < 4 ГБ или диск < 60 ГБ);
  2. «Диск» — список дисков с размером и типом, SSD выбран по умолчанию, остальные диски
     не трогаем, предупреждение «все данные будут удалены»;
  3. «Установка» — прогресс и слайды с железом ПК (без рекламы);
  4. «Готово» — «Извлеките флешку», кнопка «Перезагрузить».
  Язык (ru), раскладки (us,ru; Alt+Shift), часовой пояс (Europe/Moscow) не спрашиваются.
- [ ] **Извлечение флешки:** после «Перезагрузить» — экран на весь монитор
  «Извлеките установочную флешку», перезагрузка сама, как только флешка отключена.
- [ ] **Разметка:** весь выбранный диск, одна ФС ext4, без шифрования.
- [ ] **Имя компьютера** — автоматически: `elite-` + последние 6 символов MAC.
- [ ] **Учётки:** `manager` («Менеджер», пароль общий) и `eliteadmin` («Администратор»,
  пароль общий, в образе только хэш). Вход всегда через экран входа, без автовхода.
- [ ] **Паспорт ПК:** процессор, ОЗУ, диск (модель, размер, SSD/HDD), видеокарта,
  сеть и MAC, серийный номер платы — на слайдах и в файле `/etc/elite/hardware.txt`.
- [ ] **Без интернета:** всё ставится с флешки, обновления — после подключения к сети.

## Найдено при проверке ISO в виртуалке (26.10.2026)

- [ ] **Live-сессия: нет пользователя и автовхода.** Со сборкой без рекомендуемых пакетов
  в образ не попали `user-setup` и `sudo`, поэтому live-config не создаёт пользователя `user`
  и не включает автовход. Добавить оба пакета в `base.list.chroot`.
- [x] Заставка Plymouth: корона, надпись и прогресс на месте, на экране 16:10 без искажений.

## Найдено при проверке установщика (27.10.2026)

- [x] **Меню GRUB уходило в текстовый режим** (кириллица — «???»): не подгружался драйвер
  `vbe`, `loadfont unicode` искал шрифт не там, шрифты Inter были с огромными глифами.
  Исправлено в `config/bootloaders/grub-pc/` (нужна пересборка); с исправлением тема
  проверена в виртуалке — графит, корона, русские пункты, золотое выделение.
- [ ] **Мастер EliteSIP открывается в live-сессии** поверх установщика. Отключить
  автозапуск EliteSIP в live-режиме (оставить в установленной системе).
- [ ] **Боковая панель Calamares: «Заметки»** вместо «Добро пожаловать» — не применилось
  имя из `notesqml-elite.conf`.
- [ ] **Кнопки Calamares на английском** на первом экране (Back / Next / Cancel):
  установщик запускается от root без русской локали — передать `LANG=ru_RU.UTF-8`.
- [ ] **В паспорте ПК — дисковод `fd0`**: исключить флоппи (major 2) в `elite-hwinfo`.
- [ ] **Видеокарта «Device 1234:1111»**: нет базы названий PCI — добавить пакет `pci.ids`.
- [x] Calamares открывается сам по пункту «Установить EliteLinux», на весь экран, в теме;
  экран приветствия показывает железо и предупреждение о памяти; экран «Диск» — только
  «Стереть диск», один раздел `elite-root` ext4; окно подтверждения на русском.
- [ ] **Сама установка и первый запуск установленной системы ещё не проверены** —
  виртуалка с 3 ГБ на ноутбуке с 7,6 ГБ без подкачки вызвала нехватку памяти
  (OOM убил QEMU и Claude Code).

## Известные хвосты (найдены при сборке)

- [ ] **EliteSIP: зависимость `libicu74`.** Пакет собран под Ubuntu 24.04, в Debian 13
  есть только `libicu76`. Сейчас `scripts/prepare-packages.sh` при сборке меняет
  зависимость на `libicu76 | libicu74`; правильно — поправить упаковку в проекте EliteSIP.
- [ ] **Яндекс Телемост — веб-ярлык.** Официального клиента для Linux нет; если появится,
  заменить `telemost.desktop` на него.
- [ ] **Автоустановка с флешки (preseed).** Тестовый ISO ставится обычным установщиком
  Debian; нужен preseed: разметка всего диска, учётки `eliteadmin` и пользователя,
  русская локаль.
- [ ] **Оптимизация под HDD.** zram, preload, планировщик BFQ, отключение лишних служб —
  в сборку ещё не добавлены.
- [ ] **Telegram в `/opt/telegram`.** Каталог доступен на запись группе `users`, чтобы
  работало встроенное автообновление; проверить, что обновление действительно проходит.
